# Smart Habit Tracker

A responsive productivity dashboard with rewards, progress tracking, and task management features.

## Features
- Add/Edit/Delete Tasks
- Reward Points System
- Progress Bar
- Dark Mode
- Task Pinning
- Local Storage Support
- Completion Statistics

## Tech Stack
- HTML
- CSS
- JavaScript
